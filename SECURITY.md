# Security Policy

## Supported Versions

| Version         | Supported |
| --------------- | --------- |
| 4.0.0-canary.x  | Yes       |
| < 4.0.0-canary  | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.** Instead, please use one of the following methods:

1. **GitHub Security Advisories**: Use the [Report a vulnerability](https://github.com/fdff87554/hyper/security/advisories/new) feature on this repository.
2. **Email**: Contact the maintainer directly via the email listed on the [GitHub profile](https://github.com/fdff87554).

### What to include

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fix (if applicable)

### Response timeline

- **Acknowledgement**: Within 72 hours of the report
- **Initial assessment**: Within 1 week
- **Fix or mitigation**: Depends on severity, but critical issues will be prioritized

### Scope

This policy covers the Hyper terminal application and its build/distribution pipeline. It does not cover third-party plugins installed by users.
